# Embedded Systems Projects

This repository contains the projects and practical work I completed during my 10–15 day embedded systems training.

During the training, I learned to write and implement programs using Arduino and worked with different electronic components and circuits. I also simulated the projects using Proteus to test and understand their working.

## Topics Covered
- Arduino Programming
- IR Sensor
- LCD
- LDR
- Motor Driver
- PNP Transistor
- Home Circuitry
- Circuit Simulation using Proteus

This repository represents my hands-on learning and practical experience in embedded systems.
